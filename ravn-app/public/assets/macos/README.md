# macOS Distribution Packages (.dmg)
Place production DMG files in this directory:
- Ravn-Universal.dmg
- Ravn-AppleSilicon.dmg
- Ravn-Intel.dmg

These files are statically served at:
`https://ravn.purrfectpal.studio/assets/macos/Ravn-Universal.dmg`
and aliased at:
`https://ravn.purrfectpal.studio/download/Ravn-Universal.dmg`
